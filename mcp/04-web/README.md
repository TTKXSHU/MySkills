# 04-web — 网络与浏览器

> 网页抓取与浏览器自动化

## 包含

| MCP | 说明 | 层级 |
|---|---|---|
| [fetch](fetch/) | 抓网页转 Markdown | **全局** |
| [browser](browser/) | 浏览器自动化（点击/填表/截图） | **项目级** |

## 区别

| | fetch | browser |
|---|---|---|
| 能力 | 只读，抓内容 | 可交互，能点能填 |
| 开销 | 极小 | 大（要起浏览器） |
| 适用 | 读文档、读博客 | 登录后操作、动态页面、测试 |
| 配置 | 全局 | 按项目 |

## 选择原则

1. **能用 fetch 就用 fetch** —— 轻量、快、无状态
2. browser 只在需要**交互**时才用（登录、点按钮、填表、截图验证）
3. browser 挂在**具体项目**下，不全局启用

## ⚠️ 风险

浏览器 MCP 可控制真实浏览器，**可能复用你的登录态**。只在信任的场景启用。
